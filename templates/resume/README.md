# Resume templates

`german-professional/` is the default template for German CV exports. Its `template.json` is the canonical layout-token and ATS contract; its HTML/CSS files are self-contained and use only system fonts.

The files directly in `templates/resume/` remain the `resume-legacy` compatibility fallback. Keep the reading order linear, use real headings and lists, and avoid photos, icons, skill bars, layout tables, external fonts, and external resources.
